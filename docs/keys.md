# Keys

| Action | Default | Does |
|---|---|---|
| Toggle overlay | `End` | shows or hides the overlay |
| Toggle effects | `Home` | turns every effect off or on |
| Apply | `F10` | compiles the changed effects and rebuilds the chain, as the Apply button does |
| Toggle frame generation | `Insert` | turns lsfg-vk's frame generation off, and back on at its multiplier |
| Hold to preview | `F8` | hides the overlay while held; the game still gets no input |

Rebind any of them on the Keys card: click a key, and while it reads Press a key, press the new one, or
click it again to cancel. A key another action already uses is refused. Keys are saved for every game. No
action is tied to `Esc`, so it can be bound like any other key.
